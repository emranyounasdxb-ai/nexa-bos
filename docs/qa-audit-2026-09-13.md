## Findings and corrections

| Finding | Evidence and root cause | Correction |
| --- | --- | --- |
| Sidebar label could not be dismissed with Escape | A new real-browser regression failed because `#application-sidebar-tooltip` remained after Escape while its trigger retained focus. The shared rail had hover/focus handlers but no Escape or navigation-lifecycle dismissal. | Added listener cleanup, non-consuming Escape dismissal, and label/ARIA cleanup on activation, scrolling, viewport and navigation changes. Popup behavior, focus management, labels, icons and permissions are unchanged. |
| Alembic configuration deprecation | Full API run passed but emitted a warning for legacy path-separator handling. | Replaced `version_path_separator = os` with supported `path_separator = os`. The existing single `.` import path and migration directory are unchanged; no migration was edited or added. Verified with deprecation warnings treated as errors. See [Alembic configuration documentation](https://alembic.sqlalchemy.org/en/latest/tutorial.html). |
| TL portal spacing assertion predated the approved shell | Test expected zero breadcrumb top offset; the current shared header intentionally uses 18px desktop and 14px mobile padding. | Assert those exact approved offsets; retain card, tab, permission, focus and overflow checks. |
| Mobile filter test measured a collapsed panel | The responsive filter panel starts collapsed on mobile, so the grid had no rendered geometry. | Assert collapsed state, open it through its real button, then run the original column count, 32px control size, alignment and overflow checks. |
| Dense-table typography assertion was stale | Test expected 15px cells; the approved shared dense-table style is 14px with 12px vertical padding. | Update the exact font-size expectation; retain pagination counts, padding and responsive checks. |
| Work Areas dropdown clipped at the document edge | The dashboard moved Work Areas to its final section, but the absolutely positioned menu still opened below it. Even centered scrolling could not reveal the complete menu: rendered mobile bounds were y=492.375, height=352, bottom=844.375 in an 844px viewport. | Open this end-of-page menu above its trigger, bound its height and allow internal scrolling on short screens. Preserve links, labels, permissions and the full `ratio: 1` visibility assertion; remove the unsuccessful extra-scroll workaround from the test. |
| Role matrix used removed branding and premature measurements | Keyboard test still targeted the deliberately removed duplicate sidebar emblem, and dashboard geometry was checked before loading settled. | Assert the actual first desktop control, Light theme, and wait for loading to settle. All positive/negative permission checks remain unchanged. |
| One audit-run interference failure | A separate tooltip reproduction logged in as the same disposable Owner during the initial Create User test. The existing single-active-session rule invalidated the first session. | Run browser checks sequentially. The unchanged desktop Create User test subsequently passed. Authentication/session behavior was not weakened or changed. |

The new tooltip test also explicitly moves the pointer away before repeated hover entry. Dismissing a tooltip while the pointer remains over its trigger does not generate a new pointer-entry event; this test-driver correction does not change application behavior.
